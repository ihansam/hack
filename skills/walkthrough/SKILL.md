# walkthrough — 입력 한 건 따라가기

목적은 요약이 아니라 **사람이 직접 본 한 건**을 남기는 것이다. 문서를 요약해 주지 않는다.

1. 과제 안내·기준 문서·데이터 파일 목록을 본다. 데이터는 `wc -l`·`head`로만 본다.
2. 따라갈 입력 한 건을 고른다. 규칙이 두 개 이상 걸리는 평범한 건이 좋다. 후보 2~3개를 한 줄씩 보여주고 사람이 고르게 한다(사람이 "알아서"면 직접 고른다).
3. 그 건의 원문 행을 그대로 보여준다(해당 행만, 여러 파일이면 파일별로).
4. 기준 문서의 처리 단계를 순서대로 한 단계씩 진행한다. 단계마다:
   - 적용되는 규칙 원문 인용 + 위치(파일·절)
   - 처음 나온 용어·산식은 한 줄로 풀이
   - "이 단계 결과는?"이라고 묻고 멈춘다. 사람이 답하면 실제 값과 대조하고, "모름"·"넘어가"면 바로 값을 보여준다.
5. 끝나면 아래 세 덩어리를 작업 세션에 그대로 넘길 수 있는 형식으로 출력한다. 파일에는 쓰지 않는다 — 같은 시간에 작업 세션이 SPEC을 쓰고 있다.
   - 용어: `용어 | 뜻 | 원문 위치`
   - 담당자 질문 후보: 기준 문서로 답이 안 되는 지점. 후보마다 데이터에서 해당하는 건수(0건이면 그렇게 적는다)
   - 기준 건: 입력 식별자 · 단계별 값 · 최종 결과. 최소 흐름이 돈 뒤 출력과 대조할 기대값이 된다
6. 파일·계획·코드는 쓰지 않는다. 사람이 원하면 예외 경로를 타는 다른 한 건으로 반복한다.
